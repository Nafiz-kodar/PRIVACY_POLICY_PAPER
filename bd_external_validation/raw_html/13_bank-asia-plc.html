Access Permission: We would like to inform you that the Bankasia Smart App has acquired the following permissions on user device. These permissions have been granted based on user request and are necessary for the app's functionality. Please find the explanation, usage, and user control details below:


Location Permissions:

Explanation: This permission allows the Bankasia Smart App to access the user's device location in order to provide the user with the location of nearby Bankasia branches and ATMs.

Usage: The app will only use the device's location to display the location of Bankasia branches and ATMs to the user. User control: Users can control this permission in the app settings or by adjusting their device's location access settings.

Camera, READ & WRITE_EXTERNAL_STORAGE, MANAGE_EXTERNAL_STORAGE permission:

Explanation: These permissions are required to allow the Bankasia Smart App to capture and upload images of QR codes. Usage : The app will only access and manage files that are related to its own functionality, such as caching data or downloading files related to transactions.

User control: Users can control these permissions in the app settings or by adjusting their device's storage access settings.


READ_CONTACTS permission:

Explanation: This permission is required to allow the Bankasia Smart App to access the user's contacts in order to facilitate mobile recharge transactions.

Usage: The app will only access the user's contacts to retrieve mobile numbers for recharge transactions. The app will not store or share contact information.

User control: Users can control this permission in the app settings or by adjusting their device's contact access settings.


ACCESS_NETWORK_STATE, READ_PHONE_STATE permission:

Explanation: These permissions are required to allow the Bankasia Smart App to access network to facilitate network-related functionalities.

Usage: The app will only access network and phone information for its own functionality and will not share or store this information.

User control: Users can control these permissions in the app settings or by adjusting their device's network and phone access settings.


USE_BIOMETRIC permission:

Explanation: This permission is required to allow the Bankasia Smart App to use biometric authentication, such as fingerprint, to authenticate the user during the login process.

Usage: The app will only use the user's biometric data for authentication purposes and will not share or store this data. User control : Users can control this permission in the app settings or by adjusting their device's biometric access settings.


USE_SMS permission:

Explanation: This permission is required to allow During Digital Nano Loan application in Smart Apps, SMS permission needed just for counting the no of SMS in customer mobile. Quantity of SMS need to categorize customer group during loan application.

Usage: The App only use the number of SMS by quantity and will not share or store this data. User control : Users can control this permission in the app settings or by adjusting their device's SMS access settings.
